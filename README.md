# The gatekeeper (Godot 4 Prototype)

เกมแนว Papers Please ที่เล่นได้จริง: ตรวจเอกสารผู้ยื่นขอเข้าเมือง เทียบรูปถ่ายกับคนที่มาที่ช่อง เทียบกับกฎที่เปลี่ยนไปในแต่ละวัน แล้วกด "อนุมัติ" หรือ "ปฏิเสธ" ภายในเวลาจำกัด

## วิธีเปิดเล่น

1. ติดตั้ง [Godot 4.3+](https://godotengine.org/download) (เวอร์ชัน Standard พอ ไม่ต้องใช้ .NET)
2. เปิด Godot > Import > เลือกไฟล์ `project.godot` ในโฟลเดอร์นี้
3. กด F5 (หรือปุ่ม Run) → เล่นได้เลย

## กติกา

- ผู้ยื่นเอกสารสุ่มขึ้นมาทีละคน มีชื่อ สัญชาติ เลขพาสปอร์ต วันหมดอายุ จุดประสงค์ วีซ่า และ **รูปถ่าย 2 รูป** (รูปในเอกสาร vs รูปคนที่มาที่ช่อง — บางครั้งไม่ตรงกัน ต้องสังเกตเอง)
- กฎเพิ่มความยากขึ้นทุกวัน:
  - Day 1: ห้ามเอกสารหมดอายุ
  - Day 2: แบนสัญชาติหนึ่งประเทศ (สุ่มทุกวัน)
  - Day 3: รูปถ่ายต้องตรงกับคนที่มาที่ช่อง
  - Day 4: จุดประสงค์ "Work" ต้องมีวีซ่า
- มีเวลาต่อคน (25 วิ) ถ้าช้าเกินไปนับว่าพลาด
- พลาดครบ 5 ครั้ง = เกมจบ (ตกงาน) / ผ่านครบ 6 วัน = ชนะ

## 🎨 เอาแบบ/รูปของตัวเองมาใส่แทนได้

เกมนี้ถูกเขียนให้ **โหลดรูปจากโฟลเดอร์ `assets/` แบบอัตโนมัติ** ไม่ต้องแก้โค้ดเลย แค่เอาไฟล์ PNG/JPG ของตัวเองไปวางทับ/เพิ่มในโฟลเดอร์ที่ถูกต้อง แล้วรันเกมใหม่:

```
assets/
├── portraits/        ← รูปหน้าคน (ใส่กี่ไฟล์ก็ได้ ระบบสุ่มเลือกเอง)
│   ├── portrait_01.png
│   ├── portrait_02.png
│   └── ... (เพิ่ม/ลบ/เปลี่ยนชื่อไฟล์ได้ตามใจ ขอแค่เป็น .png/.jpg)
├── stamps/
│   ├── approve.png   ← ต้องชื่อนี้เป๊ะ ๆ (แสดงตอนกด APPROVE)
│   └── deny.png      ← ต้องชื่อนี้เป๊ะ ๆ (แสดงตอนกด DENY)
└── ui/
    ├── background.png    ← พื้นหลังทั้งหน้าจอ
    └── passport_bg.png   ← พื้นหลังของแผงเอกสาร (กระดาษพาสปอร์ต)
```

**คำแนะนำขนาดไฟล์**
- `portraits/*` : สี่เหลี่ยมจัตุรัสประมาณ 256×256px (ถ้าไม่ใช่จัตุรัสก็ยังใช้ได้ แค่จะถูกครอปกลางภาพ)
- `stamps/approve.png`, `stamps/deny.png` : พื้นหลังโปร่งใส (PNG มี alpha) ขนาดประมาณ 300×140px จะดูเหมือนตราปั๊มที่สุด
- `ui/background.png` : อัตราส่วนใกล้เคียงจอ เช่น 960×540 หรือใหญ่กว่า
- `ui/passport_bg.png` : แนวตั้ง ประมาณ 500×650px

**ถ้าไม่ใส่ไฟล์เอง** ระบบจะสร้างภาพ placeholder ให้อัตโนมัติ (สี่เหลี่ยมสีพร้อมกรอบสำหรับรูปคน, ไม่มีตราปั๊ม/ไม่มีพื้นหลังพิเศษ) เกมยังเล่นได้ปกติ 100%

> หมายเหตุ: ระบบโหลดไฟล์ด้วย `DirAccess` ที่อ่านจากโฟลเดอร์โปรเจกต์โดยตรง ใช้ได้ชัวร์ตอนรันในโปรแกรม Godot Editor (ตอนพัฒนา/ทดสอบ) ถ้าจะ export เป็น .exe ในอนาคตและอยากให้ยังสลับรูปเองได้หลัง export ต้องปรับให้โหลดจาก `user://` แทน — บอกได้ถ้าต้องการให้ผมทำส่วนนี้เพิ่ม

## ไฟล์ในโปรเจกต์

- `project.godot` — ไฟล์ตั้งค่าโปรเจกต์ (จุดเริ่มเกมคือ `Menu.tscn`)
- `Menu.tscn` / `Menu.gd` — **หน้าเมนู แยกเป็นคนละ scene ต่างหากแล้ว** มีแค่ปุ่ม START WORK กดแล้วเปลี่ยนไป scene เกม (`Main.tscn`) ด้วย `get_tree().change_scene_to_file()`
- `Main.tscn` — ฉากเกมหลัก UI ทั้งหมดเป็น node จริงที่แยกกัน (เปิดดูใน Scene panel ได้เลย เช่น `HUDLabel`, `DocumentPanel`, `RulebookPanel`, `TimerBar`, `ApproveButton` ฯลฯ)
- `Main.gd` — สคริปต์อ้างอิง node เหล่านั้นด้วย unique name (`%NodeName`) แล้วเติมแค่ส่วนที่เปลี่ยนแปลงตอนเล่น (ข้อมูลผู้ยื่นเอกสาร, รูปที่โหลดมา, ตัวจับเวลา, สถานะเกม, เงิน)
- `assets/` — รูปภาพตัวอย่าง (placeholder) ที่สร้างไว้ให้แล้ว ลองรันเกมดูก่อนได้เลยโดยไม่ต้องใส่อะไรเพิ่ม

> ถ้าจะเพิ่ม node ใหม่ใน `Main.tscn` หรือ `Menu.tscn` เอง แนะนำวางไว้ใต้ container ที่มีอยู่ (เช่นใต้ `RootVBox` หรือ `DocumentVBox`) ไม่ใช่ลอยอยู่นอก container เพราะ container จะเป็นตัวจัดตำแหน่ง/ขนาดให้อัตโนมัติ ถ้าอยากให้สคริปต์เข้าถึง node นั้นได้ ให้ติ๊ก "Access as Unique Name" (คลิกขวาที่ node หรือกด % ข้าง node ใน Scene panel) แล้วเรียกด้วย `%NodeName`

## ต่อยอดได้อีก

- เพิ่มเสียงปั๊มตรา, เสียงพลิกหน้าเอกสาร
- เพิ่มระบบเงินเดือน/ค่าเช่าบ้านแบบเกมต้นฉบับ เพื่อสร้างแรงกดดันเรื่องความเร็ว
- เพิ่มเอกสารหลายใบต่อคน (พาสปอร์ต + ใบอนุญาตทำงาน) ให้ต้องเทียบข้อมูลข้ามเอกสาร
- แยกกฎแต่ละวันออกเป็นไฟล์ resource (.tres) แทนการ hardcode ใน `_set_rules_for_day()`

บอกได้เลยถ้าอยากให้ผมต่อยอดส่วนไหนเพิ่ม
